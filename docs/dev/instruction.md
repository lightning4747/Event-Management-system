# Developer & Git Instructions

1. **Git Commit Message Rules:**
   - Always commit to git with a single-line, simple commit message.
   - Do not include useless details (e.g. "task 17 done" or source code details).
   - Use a simple message in one line even after small changes, especially in modified files.

2. **Coding Standard Compliance:**
   - Always follow the coding standards defined in [docs/dev/coding-standard.md](docs/dev/coding-standard.md).

3. **Project Documentation:**
   - Ensure the root directory contains a simple and minimal README.md that points to the main documentation hub.
